Telegram Downloader

Download with GitHub Actions Only

Paste any public Telegram link → trigger a GitHub Action → download the video as an artifact. No local Python needed after setup.

● Powered 100% by GitHub Actions

0 Paste your Telegram link

1 One-time Setup (only once)

1

Push this repo to GitHub
Create a new repository and push all files to the main branch.

2

Add Secrets (Settings → Secrets and variables → Actions)

Create these two secrets:

TELEGRAM_API_ID     → your api_id (number)
TELEGRAM_API_HASH   → your api_hash (string)

Optional but recommended: TELEGRAM_SESSION (StringSession – see README)

3

Enable GitHub Pages
Settings → Pages → Source = GitHub Actions

⚠️ Never put your API_ID / API_HASH in the code. Always use GitHub Secrets.

2 How to Download any Telegram Video

1

Go to your repository → Actions tab

2

Click “Download Telegram Media” on the left

3

Click “Run workflow”

4

Paste the Telegram link (example below) and click Run workflow

https://t.me/odiamahabharat/154
5

Wait 30–90 seconds → open the finished run → download the telegram-media artifact

✅ The video/file will appear as a downloadable artifact on the Actions run page.

3 Local fallback (optional)

You can also run it on your computer: 

export TELEGRAM_API_ID=your_api_id
export TELEGRAM_API_HASH=your_api_hash
python telegram_downloader.py "https://t.me/odiamahabharat/154"
